src/core/types.ts MUST export:
- Branded basis types: `Real<T=number>`, `Nominal<T=number>` via a `unique symbol` tag (RESEARCH Pattern 2).
- Constructors: `asReal(x:number):Real`, `asNominal(x:number):Nominal`.
- Runtime guard: `assertReal(p:{basis:'real'|'nominal'}, ctx:string):void` — throws `Error("Basis violation in {ctx}: expected real, got {basis}")`.
- `interface SourcedParam { value:number; basis:'real'|'nominal'; source:string|null; note?:string }` (Phase-2-ready; synthetic values use `source:null`).
- `interface Anchors { median:SourcedParam; top10:SourcedParam; top1:SourcedParam; top01:SourcedParam }` (the 4 wealth-percentile anchors; percentile semantics: median=p50, top10=p90, top1=p99, top01=p99.9).
- `interface ReturnByTier { median:SourcedParam; top10:SourcedParam; top1:SourcedParam; top01:SourcedParam }` (real return rates per anchor).
- `interface Params { anchors:Anchors; returnByTier:ReturnByTier; dragStrength:SourcedParam; horizon:number; distributionEvolution:'endogenous'|'fixed-shape-scaled'; savings:SourcedParam }` (horizon ≤ 60, D-09; savings is real, D-08).
- `interface Inputs { currentWealth:number; annualSavings:number }`.
- `interface YearSnapshot { year:number; anchorWealth:{median:number;top10:number;top1:number;top01:number}; userWealth:number; userPercentile:number; topSetPercentile:number; assetInflation:number }`.
- `interface ProjectionResult { series:YearSnapshot[]; relativePosition:Array<{year:number;userShare:number;userRank:number}> }`.

src/core/__tests__/testUtils.ts MUST export:
- `relErr(actual:number, expected:number):number` = `Math.abs(actual-expected)/Math.max(Math.abs(expected),1e-12)` (the ONE documented tolerance helper; D-11 criterion is `relErr < 1e-9`).
- `analyticOrdinaryAnnuity(W0:number, r:number, S:number, n:number):number` — independent textbook closed form `W0*(1+r)^n + (r===0 ? S*n : S*((1+r)^n-1)/r)`. MUST NOT import or reuse engine loop code.
- `makeSyntheticParams(overrides?):Params` and `syntheticInputs:Inputs` — obviously-synthetic round numbers, NO hardcoded "18" anywhere (PITFALLS P2).
- Documented distribution-test tolerance constant `DIST_TOL = 1e-6` (RESEARCH Open Question 2 — erf precision; separate from the <1e-9 annuity tolerance).
