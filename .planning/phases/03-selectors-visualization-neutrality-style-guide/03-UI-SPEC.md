# Phase 3 — UI Design Contract

> Visual and interaction contract for Phase 3 (Selectors, Visualization & Neutrality Style Guide). Generated by gsd-ui-researcher, verified by gsd-ui-checker.

This phase has **no input forms, no CTAs, no destructive actions, no live recompute, no mobile/touch polish** (all Phase 4). The deliverable is a dev-harness page that renders three neutral ECharts charts from `DEFAULTS`, a shared log/linear toggle, tooltips, a citation footer, and the neutrality style guide markdown artifact. **Neutrality is the dominant visual constraint** (PROJECT.md): no semantic red/green, color must never imply good/bad, no value-laden copy, no axis tricks.

## Spacing Scale

Declared values (multiples of 4; Tailwind v4 default 4px base):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline gaps (toggle label ↔ control), tight caption leading offsets |
| sm | 8px | Caption-to-chart gap, footer citation line-item spacing |
| md | 16px | Default intra-component padding; chart card inner padding |
| lg | 24px | Gap between the three stacked charts; section padding |
| xl | 32px | Page content vertical rhythm; harness header ↔ first chart |
| 2xl | 48px | Major break above the citation footer |
| 3xl | 64px | Page top/bottom outer margin (desktop) |

Exceptions: none. ECharts internal `grid`/`padding` values must also resolve to multiples of 4 (e.g. `grid: { top: 24, right: 16, bottom: 32, left: 48 }`) so chart internals stay on the same rhythm.

## Typography

Exactly 4 sizes, exactly 2 weights (400 regular, 600 semibold). No italic, no other weights.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Display | 28px | 600 | 1.2 |
| Heading | 20px | 600 | 1.2 |
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.5 |

Mapping:
- **Display 28/600** — harness page title only (single instance).
- **Heading 20/600** — each chart's neutral title (3 instances); style-guide-governed wording.
- **Body 16/400** — neutral scale-explanatory copy (VIZ-02), the fixed relative-position neutrality caption (D-11).
- **Label 14/400** — chart axis labels, legend entries, tooltip text, footer citation lines. Tabular numerals enforced here.

ECharts `textStyle` must be configured to these exact sizes/weights (do not accept ECharts default 12px). Tooltip body: Label 14/400. Axis names: Label 14/400.

## Color

Neutral, value-free palette. **No red/green anywhere.** Series colors are categorical hues of equal perceptual weight (none "good", none "bad"). The user series is distinguished by a single neutral accent, not by a positive/negative connotation.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` (page) / `#F8FAFC` (slate-50) chart card surface | Page background, chart plot surfaces, whitespace |
| Secondary (30%) | `#475569` (slate-600) text / `#E2E8F0` (slate-200) borders & gridlines | Body/label text, chart card borders, ECharts axis lines, faint gridlines |
| Accent (10%) | `#0F766E` (teal-700) | **User's own series line** in all three charts; the active state of the log/linear toggle. Nothing else. |
| Destructive | not used | No destructive actions exist in this phase |

Accent reserved for: (1) the user trajectory line/series across all three charts, (2) the active segment of the log/linear toggle. Never used for emphasis, never for tier series, never to imply the user is winning or losing.

**Tier series palette (categorical, neutral — equal weight, colorblind-safe, NOT red/green):**

| Series | Color | Notes |
|--------|-------|-------|
| User | `#0F766E` teal-700 (accent) | Only the user line uses accent |
| Median (p50) | `#64748B` slate-500 | Neutral grey-blue |
| Top 10% (p90) | `#7C3AED` violet-600 | Categorical hue |
| Top 1% (p99) | `#2563EB` blue-600 | Categorical hue |
| Top 0.1% (p99.9) | `#0891B2` cyan-600 | Categorical hue |
| Tier-threshold reference bands/lines (D-10) | `#CBD5E1` slate-300 at ≤30% opacity, 1px dashed | Faint, unobtrusive, behind data; never filled with a connotative color |

Rationale (NEUT palette clause, D-03): the palette deliberately avoids any hue pair that reads as approval/alarm. Differentiation is by distinct categorical hue + legend, not by semantic temperature. This palette decision is itself recorded in the neutrality style guide (D-02/D-03) and is gated by Phase 5.

## Copywriting Contract

This phase has no CTA, no empty state (charts always render from frozen `DEFAULTS` — D-05), and no error state in normal operation (deterministic engine on hardcoded params). The copy that matters is **neutral chart/explanatory copy** governed by the neutrality style guide. All strings below must pass the Phase 5 NEUT-02 review against the style guide authored in this phase.

| Element | Copy |
|---------|------|
| Primary CTA | none — no interactive entry in Phase 3 (deferred to Phase 4) |
| Empty state heading | not applicable — charts always have data from `DEFAULTS` |
| Empty state body | not applicable |
| Error state | If the engine throws (basis violation / malformed `DEFAULTS`), the harness shows a single neutral diagnostic line, not a styled error UI: `"Projection unavailable: the model could not produce a result from the current parameters."` (developer-facing harness only; no remediation CTA this phase) |
| Destructive confirmation | not applicable — no destructive actions exist in this phase |

**Neutral chart copy contract (the real Phase 3 copy surface — all style-guide-governed, factual, no blame/virtue, no alarm punctuation):**

| Surface | Required copy intent (exact wording authored against the style guide; examples below are neutral templates) |
|---------|------|
| Page / harness title | Plain descriptor, no editorializing. Template: `"Wealth projection — model output preview"` |
| Chart 1 title (time-series) | `"Projected wealth over time"` |
| Chart 2 title (divergence overlay) | `"Wealth by tier over time"` |
| Chart 3 title (relative-position) | `"Position in the wealth distribution over time"` |
| Log/linear scale explanatory copy (VIZ-02) | Neutral, describes what each scale *shows*, never which is "better". Template: `"Log scale: equal vertical distance represents equal percentage change, making compounding visible. Linear scale: equal vertical distance represents equal absolute change."` |
| Relative-position fixed neutrality caption (D-11, highest design risk) | Must state shares/rank can move while all tiers' real wealth still grows. Template: `"This shows the user's rank within the distribution. Rank can move down while the user's real wealth still grows — every tier's wealth increases over this horizon. See the wealth-by-tier chart above for absolute amounts."` This exact caption is **seeded into the neutrality style guide (D-04)** so Phase 5 reviews it against the same artifact. |
| Citation footer (VIZ-06 minimum) | One neutral line tracing displayed defaults to named research, reading `sourceName` (and `url` when present) from `src/data/sources.ts` `SOURCES`. Template: `"Default parameters sourced from: Fagereng et al. (2020); Bach et al. (2020); Saez & Zucman (2016/2019); Jordà, Schularick & Taylor (2019); McKinsey Global Institute (2021/2023). See sources for definitions and caveats."` Links use `SourceRecord.url`. No editorial framing of the sources. |

**Banned in all of the above (style-guide lexicon, D-02):** value-laden adjectives/verbs (e.g. "soar", "plummet", "trapped", "winners", "losers", "unfair", "elite"), alarm punctuation ("!"), blame/virtue framing, zero-sum / finite-pie language. The relative-position surfaces (Chart 3) carry the strictest scrutiny per Pitfall 4.

## Interaction & Chart Contract

Prescriptive contract for the executor. All charts are ECharts 6 via `echarts-for-react`, fed by **memoized selectors** (`Zustand/DEFAULTS params → memoized selector → model output → ECharts option`); charts never transform raw engine output inline (CLAUDE.md mandatory pattern, ARCHITECTURE.md functional-core/imperative-shell).

### Layout (D-05, D-06)
- Single dev-harness page. Three charts **stacked vertically**, all visible at once, in fixed order: (1) time-series growth → (2) multi-tier divergence overlay → (3) relative-position trajectory.
- **No primary/secondary visual hierarchy** between charts (neutrality, D-06): identical card treatment, identical title typography (Heading 20/600), identical width, equal `lg` 24px gap. No chart is larger, boxed, or highlighted relative to the others.
- Each chart in a neutral card: `#F8FAFC` surface, 1px `#E2E8F0` border, `md` 16px inner padding, no shadow elevation that implies importance.
- Chart minimum height: 320px each (enough to make multi-decade compounding legible). Width: fill content column.

### Shared log/linear toggle (D-07, VIZ-02)
- **One shared toggle**, two segments (`Linear` | `Log`), **default = Log**. Governs **only** Chart 1 (time-series) and Chart 2 (divergence) Y axis (`type: 'log'` ⇄ `'value'`).
- Chart 3 (relative-position) is **always linear**, has **no toggle affordance**, and is unaffected by it.
- Toggle placement: above Chart 1, single instance, clearly scoped (a Label 14/400 sentence: `"Scale applies to the two wealth charts."`).
- Active segment uses accent `#0F766E`; inactive segment Secondary text on Dominant surface. Toggle is a real control (keyboard-focusable, `role`/`aria-pressed` on segments) even though it is the only interactive element this phase.
- Neutral scale-explanatory copy (Body 16/400) sits adjacent to the toggle (VIZ-02).

### Chart 1 — Time-series wealth (VIZ-01)
- Single series: user's `userWealth` vs `year`, accent `#0F766E`.
- X axis: year (0 → horizon), Label 14/400, neutral name `"Year"`.
- Y axis: real wealth, scale governed by shared toggle, neutral name `"Real wealth (today's money)"`. Tabular-num formatted, abbreviated large numbers (e.g. `1.2M`) — formatting in the selector/chart layer, never the engine (CLAUDE.md round-at-display).
- Tooltip (VIZ-03): year, wealth, user percentile/rank, tier at inspected point.

### Chart 2 — Multi-tier divergence overlay (VIZ-04, VIZ-03 via D-08)
- Four tier series (median p50, top10 p90, top1 p99, top0.1 p99.9) from `anchorWealth`, plus the user series (accent). Tier colors per the categorical palette above. Equal line weight (2px) for all; **no series visually dominant** (neutrality) except the user line carries the single accent hue for findability — not heavier weight.
- Shared scale toggle applies (Log default).
- **Combined tooltip (D-08):** at the hovered year, show **all series** (user + median + top1% + top0.1% + top10%) each with its wealth value, **plus** the user's percentile/rank and tier. One consolidated tooltip block, neutral labels, tabular nums, aligned columns.
- Legend present, neutral labels, Label 14/400.

### Chart 3 — Relative-position trajectory (VIZ-05, D-09, D-10, D-11 — HIGHEST design risk)
- Primary trace: user's **rank (percentile 0–100)** vs `year`, from `relativePosition[].userRank`, accent `#0F766E`.
- Y axis: `0–100`, **standard orientation (100 at top), NO inversion** (D-09 — axis tricks are non-neutral). Neutral name `"Percentile rank (0–100)"`. Always linear; no toggle.
- `userShare` is **tooltip-only**, never the plotted axis (D-09 — avoids tiny-share flat-line illegibility).
- **Faint tier-threshold reference bands/lines (D-10):** horizontal markers at p50 / p90 / p99 / p99.9 boundaries using `#CBD5E1` at ≤30% opacity, 1px dashed, rendered behind the data line, neutral non-duplicating labels (`"p50"`, `"p90"`, `"p99"`, `"p99.9"`). Must not restate the divergence story or use connotative fills.
- **Tooltip (D-11 safeguard):** at the hovered year, pair the user's rank **with their growing real wealth at that same year** and their `userShare`, so a downward rank trend is never shown in isolation. Format: `Year • Rank: NN • Real wealth: $X • Share of total: Y%`.
- **Fixed neutral caption (D-11):** the caption from the Copywriting Contract is always visible directly under this chart (Body 16/400), not a tooltip-only or hover-only affordance. This caption is the chart's credibility safeguard and is seeded into the style guide (D-04).

### Citation footer (VIZ-06, Claude's-discretion: footer-line minimum)
- One neutral footer line (Label 14/400) below all charts (`2xl` 48px break above it), reading `sourceName`/`url` from `SOURCES`. Links open primary sources. No richer per-parameter panel this phase (deferred to Phase 5 unless planner finds the footer insufficient for VIZ-06).

### Neutrality style guide artifact (NEUT-01, D-01..D-04)
- Plain versioned markdown artifact (prose rules, not executable; no lint test — D-01). Path is planner's discretion; must be a stable versioned location the Phase 5 gate can cite (proposed `docs/NEUTRALITY-STYLE-GUIDE.md` or `.planning/NEUTRALITY-STYLE-GUIDE.md`).
- Must contain: (a) copy lexicon — banned value-laden words/verbs/adjectives, alarm punctuation, blame/virtue framing, with neutral rewrites (D-02); (b) chart-semantic rules — neutral axis/series labels, the relative-position caption rule, log-scale explanatory-copy tone (D-02); (c) **brief explicit palette clause** — "no semantic red/green; color must never imply good/bad" (D-03, mandated by ROADMAP Phase 3 success criterion 5); (d) the exact D-11 relative-position caption text seeded in (D-04).
- A full dedicated palette section and a formal pass/fail checklist template were explicitly NOT chosen (D-03) — keep the palette clause brief.
