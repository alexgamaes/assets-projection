## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Engine output → ECharts HTML tooltip formatter | Multi-series tooltip constructs HTML from numeric model values + string series names |
| SOURCES registry → CitationFooter anchor hrefs | SourceRecord.url values rendered as href attributes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Tampering / XSS | selectDivergenceOption combined tooltip formatter — HTML string construction | mitigate | All values in the tooltip are from numeric model output (formatWealth(value), rank.toFixed(1), year) and static string literals (seriesName constants). No user-provided strings are interpolated into the HTML. Phase 4 must maintain this when user inputs are wired in. |
| T-03-07 | Tampering / XSS | CitationFooter anchor href={c.url} | mitigate | SourceRecord.url values come from the frozen SOURCES registry in src/data/sources.ts (committed in Phase 2, not user-controlled). rel="noopener noreferrer" prevents the opened page from accessing window.opener (standard for target="_blank" links). No user-provided URL is ever passed to CitationFooter in Phase 3. |
| T-03-08 | Information Disclosure | D-11 caption not in DOM (Pitfall 7) | mitigate | Caption is a rendered p element in RelativePosChart — not ECharts annotation, not tooltip-only. Browser visual verification required (human-check above). |
| T-03-09 | Spoofing | docs/NEUTRALITY-STYLE-GUIDE.md content integrity | accept | The style guide is a committed markdown artifact. It is not executable. Phase 5 human review gate reads it directly from the repo; no runtime attack surface. |
| T-03-SC | Tampering | npm installs (handled in Plan 01) | accept | No new npm packages added in Plan 03. |
