<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Engine output → ECharts tooltip formatter | Numeric model values formatted into HTML tooltip strings |
| External ECharts renderer → browser DOM | ECharts canvas/HTML rendering from declarative EChartsOption object |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-03 | Tampering / XSS | ECharts tooltip HTML formatter in selectTimeSeriesOption | mitigate | Tooltip strings are constructed exclusively from numeric model output (result.series[i].userWealth, userPercentile, year) formatted via formatWealth() — no user-supplied strings are interpolated. Risk: near-zero in Phase 3 (hardcoded DEFAULTS only). Phase 4 must maintain this invariant when user inputs are added. |
| T-03-04 | Denial of Service | Log axis with zero/near-zero wealth values | mitigate | Log axis zero-guard applied in selector: Math.max(1, value) on series data AND yAxis.min=1 when yAxisType='log'. Both guards together prevent ECharts from receiving 0 or negative on a log axis. |
| T-03-05 | Information Disclosure | neutrality caption absent from DOM | mitigate | D-11 fixed caption is a rendered DOM element (Plan 03 RelativePosChart); not tooltip-only. Addressed in Plan 03. |
| T-03-SC | Tampering | npm installs (handled in Plan 01) | accept | All packages verified [OK] in Plan 01; no new packages added in Plan 02. |
</threat_model>
