## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| typed numeric field → onChange handler (LogSliderInput) | User enters arbitrary text in the number field; the onChange guard converts to number and rejects NaN/negative before calling the parent handler. This is the primary XSS/NaN boundary for this plan. |
| inflationRate → SummaryReadout caption | inflationRate is a number from INFLATION_RATE.value (a frozen constant), not user-supplied. No injection risk. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-02-01 | Tampering | LogSliderInput typed field | mitigate | onChange handler: `const n = Number(e.target.value); onChange(Number.isFinite(n) && n >= 0 ? n : 0)` — NaN/negative/non-finite input falls back to 0, engine never receives bad values. |
| T-04-02-02 | Tampering / Info Disclosure | SummaryReadout tooltip XSS | accept | No user-supplied string enters the readout. All values are numbers from model output (selectSummary), formatted by formatWealth and toFixed. No innerHTML, no dangerouslySetInnerHTML. Identical constraint as Phase 3 T-03-03. |
| T-04-02-03 | Tampering | selectReinflated (display layer) | mitigate | Re-inflation calls (1 + i) ** s.year where i comes from INFLATION_RATE.value (frozen constant = 0.025). No user input reaches i in this plan. Plan 03 must pass INFLATION_RATE.value, not a user-typed value. |
| T-04-02-SC | Tampering | npm installs | accept | This plan installs zero new packages. All dependencies already installed and verified at Phase 3. |
