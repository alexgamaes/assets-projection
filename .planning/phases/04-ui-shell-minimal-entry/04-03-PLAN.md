## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03-01 | Tampering | Engine called with bad inputs | mitigate | LogSliderInput boundary guard ensures currentWealth ≥ 0 and annualSavings ≥ 0 before store.setInputs. useDeferredValue ensures engine receives the debounced (validated) value. Engine itself is pure — wrong inputs produce wrong-but-non-crashing output; the sourcing guard prevents NaN propagation. |
| T-04-03-02 | Tampering | selectReinflated called with user inflation rate | accept | INFLATION_RATE.value is a frozen constant imported from defaults.ts. No user control adjusts inflation in v1 (adjustable inflation is v2 CONFIG-01). No injection path. |

No stack trace, no error object stringification. Wrap the useMemo projectionEngine call in a try/catch; on error, set rawResult to null and render the diagnostic. |
