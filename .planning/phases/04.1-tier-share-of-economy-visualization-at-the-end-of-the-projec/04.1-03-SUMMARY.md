# Phase 4.1 Plan 03: VIZ-07 AppShell Composition Summary

One-liner: AppShell extended with Chart 4 (stacked-area) and Chart 5 (donut) wired to `deriveBandShares(rawResult.series)` via memoized selectors, plus D-16 mandatory caption via prop and D-11 basis-inert note rendered per section; NEUTRALITY-STYLE-GUIDE Section 7 authored with verbatim D-16 rule byte-identical to SHARE_CAPTION.

## What Was Built

**`docs/NEUTRALITY-STYLE-GUIDE.md` (extended)**
- New Section 7 — D-16 Share-of-Economy Neutral Disclosure Rule appended (Sections 1-6 unchanged; 25 lines added only)
- Mirrors Section 6 structure exactly: Seeded date, Phase 5 NEUT-02 gate, Context, Required Caption Template (blockquote), Constraints, Neutrality Test
- Caption blockquote byte-identical to `SHARE_CAPTION` in `src/state/selectors.ts`
- No-zero-sum / no finite-pie clause documented (model is non-conserving; falling share != falling wealth)
- Sync-constraint sentence: any revision requires corresponding update to `SHARE_CAPTION`

**`src/ui/AppShell.tsx` (extended)**
- New imports: `deriveBandShares` from `'../core/tierBands.js'`; `selectShareOption, selectDonutOption, SHARE_CAPTION` from `'../state/selectors.js'`; `TierShareChart` from `'../viz/TierShareChart.js'`; `DonutChart` from `'../viz/DonutChart.js'`
- Three new `useMemo` hooks:
  - `bandShares = useMemo(() => rawResult !== null ? deriveBandShares(rawResult.series) : null, [rawResult])` — D-12: derives from rawResult, not reinflated result
  - `shareOption = useMemo(() => (bandShares !== null && rawResult !== null) ? selectShareOption(bandShares, rawResult) : null, [bandShares, rawResult])`
  - `donutOption = useMemo(() => (bandShares !== null && rawResult !== null) ? selectDonutOption(bandShares, rawResult) : null, [bandShares, rawResult])`
  - Comment annotates D-12 basis-invariance rationale
- Chart 4 section (after Chart 3, before CitationFooter):
  - `<h2>Share of total wealth by tier over time</h2>`
  - `<TierShareChart option={shareOption} caption={SHARE_CAPTION} />` (null-guarded)
  - D-11 note `<p>` (AppShell-rendered)
- Chart 5 section (after Chart 4, before CitationFooter):
  - `<h2>Final-year wealth share by tier</h2>`
  - `<DonutChart option={donutOption} caption={SHARE_CAPTION} />` (null-guarded)
  - D-11 note `<p>` (AppShell-rendered)
