## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] TypeScript: donut tooltip formatter signature mismatch**
- **Found during:** Task 1 — `npx tsc --noEmit` after implementation
- **Issue:** `tooltip.formatter` typed as `(params: CallbackDataParams) => string` is incompatible with ECharts' `TooltipFormatterCallback<TopLevelFormatterParams>` which can pass `CallbackDataParams[]` (axis trigger). Type error TS2322.
- **Fix:** Changed signature to `(params: CallbackDataParams | CallbackDataParams[]) => string`, handling array case with `Array.isArray` guard (matching existing selectors pattern).
- **Files modified:** `src/state/selectors.ts`
- **Commit:** a1acbe8

**2. [Rule 1 - Bug] TypeScript: graphic style `textAlign` property not in ECharts type**
- **Found during:** Task 1 — `npx tsc --noEmit`
- **Issue:** `graphic[].style.textAlign` not in `TextStyleProps` — removed to satisfy strict types. The center text is already centered via `left:'center'` on the graphic element itself.
- **Fix:** Removed `textAlign` from `graphic.style`; centering is achieved by `left:'center'` on the parent graphic element.
- **Files modified:** `src/state/selectors.ts`
- **Commit:** a1acbe8
